## 프로젝트 기준

| 항목 | 내용 |
|---|---|
| 개발 기간 | 3주 |
| 개발 인원 | 4명 |
| 사용자 | 학생, 교수, 관리자 |
| 기술 스택 | Spring Boot, Vue, MySQL |
| 핵심 완료 흐름 | 관리자 기초 데이터 등록 → 학생 수강 신청 → 교수 출결·성적 제출 → 관리자 성적 확정 → 학생 성적 조회 |

## 범위 결정 요약

- 1차 관리자 역할이 교무 업무를 함께 담당한다.
- 학생 사진 업로드는 2차 범위로 둔다.
- 입학·등록금·졸업 업무는 2차 범위로 둔다.
- 출결은 단순 입력·조회까지만 구현하며 최종 성적 자동 계산에는 사용하지 않는다.
- 최종 성적은 교수가 직접 입력하고 관리자가 확정한다.
- 1차에서 가장 중요한 기술 검증 대상은 수강 신청 동시성과 성적 상태 통제다.
