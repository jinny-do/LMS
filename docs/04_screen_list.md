# 학사관리 시스템 1차 MVP 화면 목록

## 1. UI 구성 원칙

- 데스크톱 웹을 우선하며 최신 Chrome을 기준으로 한다.
- 역할별 핵심 메뉴를 6개 이내로 유지한다.
- 관리자 CRUD 화면은 검색 영역, 목록 테이블, 등록·수정 폼 패턴을 공통 사용한다.
- 강좌 상세 화면 안에서 수강생, 출결, 성적을 탭으로 구분해 화면 수를 줄인다.
- 현재 학기와 성적 상태를 화면 상단에 명확히 표시한다.
- 프로필 사진은 1차에서 기본 이미지로 표시하며 업로드 기능은 제공하지 않는다.

## 2. 역할별 메뉴 구조

### 학생

```text
대시보드
수강 신청
내 시간표
성적 조회
내 정보
```

### 교수

```text
대시보드
담당 강좌
출결 관리
성적 관리
내 정보
```

### 관리자

```text
대시보드
기준정보 관리
사용자 관리
과목·강좌 관리
수강·성적 관리
변경 이력
```

## 5. 발표 시 화면 이동 순서

1. 관리자 로그인 → 학과·학생 등록
2. 과목 관리 → 컴퓨터공학과 과목 등록
3. 강좌 관리 → 2026학년도 1학기 강좌 개설
4. 학생 로그인 → 수강 신청 → 내 시간표 확인
5. 교수 로그인 → 담당 강좌 → 출결 입력 → 성적 입력·제출
6. 관리자 로그인 → 성적 확정
7. 학생 로그인 → 성적 조회 → 총 취득학점 반영 확인
